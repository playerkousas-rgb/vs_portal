## ④ 同步安全大修（「另一邊讀不到／手機全吉／懷疑登入清空後端」）

### 事故原因（確認咗）

團長個懷疑**基本上係啱嘅**。成條鏈係咁：

1. `login()` 成功之後會寫一筆登入稽核（`audit`）→ 呢筆改動會排隊 **2.5 秒後自動 push 成個本機資料庫**上後端。
2. 開機時「使唔使拉後端」以前靠**時間戳比較**。但本機 `meta.updatedAt` 喺**離線改動嗰陣都會更新**（就算之後 push 失敗）—— 所以一部過時嘅瀏覽器可以永遠「以為自己較新」→ 開機唔拉後端 → **「另一邊又讀不到」**。
3. 呢部過時瀏覽器一登入（或者任何改動）→ push → **成個過時資料庫盲蓋上後端** → 無痕度存嘅嘢冇晒 → **「登入嗰一刻清空後端」**。
4. 手機跟住開 → 由後端拉咗個已清空 db → **「直頭全吉」**。

### 修復（三層保護）

| 層 | 做法 |
|---|---|
| 後端樂觀鎖 | `saveDb` 而家要 `baseVersion`（部機上次見過嘅後端版本）。對唔上（包括舊版 app 冇送）→ **拒收**，回 `conflict:true`。版本由**伺服器派**（時間＋隨機尾數），唔會撞。 |
| 開機版本對資料 | 唔再信時間戳。後端版本 ≠ 本機 `sync.lastSyncedVersion` → 即拉；本機有未同步改動 → **聯集合併**（本機新增嘅紀錄保留，兩邊都有嘅以後端為準），唔會再「二選一」。 |
| 衝突自動復原 | push 撞版 → 自動「拉後端 → 合併 → 重存一次」，全程寫入同步紀錄＋ toast 話你知。 |
| 空機保險閘 | 清咗 cache／全新裝置（本機完全冇內容又未拉過）→ **唔會自動寫後端**，淨係等拉。 |

已知取捨：本機**離線刪除**嘅紀錄，如果另一部機未見過，合併後會「翻生」——總好過成個資料庫被盲蓋；見到再刪一次就得。

## ⑦ 體積治理：「資料庫」分頁唔會再 JSON 爆炸

團長問得好啱：成團人用，最驚「資料庫」分頁啲 JSON 撐爆。查過之後，**最大嘅食位係 APP 內申報嘅相片**：
以前 dataURL（每張可達 300KB+）直接入 db JSON —— 一到 9MB，後端就拒收，**成個同步會死**。而家：

**治本：相片唔再入 db JSON**
- APP 內「收支申報」交相：即刻經後端**上 Drive**，db 入面只留一條連結（`photosOnDrive` 標記）。
- 上載唔到（離線／未接後端）→ 照舊本地存（唔會蝕資料），遲啲可以瘦身。
- 團員入口（entry.html）交嘅相本來就已經上 Drive，唔受影響。

**治理：APP 內睇得到、清得到**
- 「總表同步」新加**體積 badge**（體積 <3MB 綠 / 3–6MB 黃 / >6MB 紅）＋「**體積檢查**」掣：
  逐分頁列出邊個食緊嘢（團員／帳目／申報連相片…），後端 `dbInfo` 都會回 `sizes`（伺服器端實數）。
- 「**相片瘦身**」掣：一鍵把舊 dataURL 相從 db 清走（有 Drive 連結嘅零損失；
  冇連結嘅會警告先，建議匯出 JSON 備份）——通常即刻騰出幾 MB。
- push 前體積預警：8.5MB 就擋住唔送（唔會等到後端 9MB 先死），叫你去瘦身。
  （**v2.4.0 起再進一步**：連呢道牆都拆埋 —— 見下 §⑧ 分件儲存，badge 只係俾你睇大細。）

**防 GAS 配額燒爆**
- `saveDb` 刪舊段由「逐行 deleteRow」改成「成梳 `deleteRows` 一次過」——
  200 段資料以前係 200 次調用（每次成頁 shift），而家一兩下搞掂。

> ⚠️ **要重新部署 Apps Script** 先有 `uploadPhotos`／`sizes`／成梳刪（v2.3.0；而家最新係 v2.5.0，見最頂「深夜」一節）。
> 未部署之前：申報相會自動退返本地存（行為同以前一樣），同步照常運作。

## 2. 試卷：支援上載 Google Form 列印 PDF

**背景（團長講法）**：Google Form 冇得 OUTPUT CSV，但可以將問題 OUTPUT 成
PDF（表單右上 ⋮ →「列印」→ 另存 PDF）—— 咁就當佢係指定格式，由系統對上。

**改法**：
- 「試卷 → 匯入」分頁新增**「上載 Google Form PDF（或 .txt／.csv）」**掣。
- PDF **喺瀏覽器入面解析**（`assets/js/lib/pdftext.js`，**零依賴** —— 為咗
  唔引入成個 pdf.js，自己寫咗：
  inflate／deflate 解壓（RFC 1950/1951）、PDF 物件掃描（唔使 xref）、
  Type0 + Identity-H 字型嘅 ToUnicode 對照（bfchar／bfrange）、
  內容流 BT/Tf/Tm/Td/TJ 文字抽取連位置）。
- Google Form 列印 PDF 嘅版面好固定：題目喺左邊界、選項一律右移一段 ——
  就係靠呢個**縮排**分返「題目」同「選項」，單選／多選認唔出就當「單選」。
- 抽出嚟嘅文字會擺返落**可編輯**嘅文字格，下面有**即時預覽**（幾多題、
  每題類型＋選項），改完先撳「匯入成新試卷」—— 唔會收收埋埋抽錯仲匯入。
- 頁碼、「必填」星標、「提交」、「Google Forms」版尾等垃圾行會自動丟走。
- 順手修咗 CSV 類型：以前 `single` 呢個字根本認唔出（regex 冇包），一定變 short。

**測試**（`tests/pdftext.mjs`，純 Node 零依賴）：
- inflate：stored／fixed／dynamic／raw 四種 block 都解得返。
- 砌咗一份同 Chrome 列印一樣結構嘅中文 PDF（Type0 + Identity-H + ToUnicode +

  「核取」關鍵字 → multi。

  匯入後喺編輯器逐題改（預覽度有講明）。

## 3. 進度紀錄：「成員進度」分頁數字同表格一致

**症狀（團長回報）**：成員進度表剔走咗管理員（唔會喺表度出現），

**改法**：分頁標籤改用 `summarizeRemote(...).memberCount` —— 標籤同表格永遠同一個數。
