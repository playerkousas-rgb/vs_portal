| # | 位置 | 本來會點 | 而家 |

## 後端張 Sheet：**唔使清**

你張 Google Sheet 係**你自己旅團專用**嘅，入面係你自己嘅資料。
清空咗 app 之後一登入，系統會自動由後端拉返落嚟 —— 呢個係正常運作，唔係漏嘢。

實測過（假後端 + 兩部機）：

| 步驟 | 結果 |
|---|---|
| 原本部機輸入 3 團員 / 2 筆帳目 → 推上 Sheet | ✅ 成功（2022 bytes） |
| 全新一部機（＝清空後重新登入），未拉之前 | 0 團員（空白，冇任何嘢） |
| 登入後自動拉 | ✅ 3 團員 / 2 帳目，一個都冇少 |

所以：

- **想由零開始自己重新輸入** → 先去 Sheet 嘅「資料庫」分頁刪走所有 row（留返第 1 行標題）
- **想攞返舊資料** → 乜都唔使做，登入就有

兩個都得，睇你想點。**重點係你張 Sheet 嘅嘢只有你自己旅團見到** ——
呢次清嘅係 Git repo 入面嗰份會種落**每一個開呢個網站嘅人**部機嘅副本，
同你張 Sheet 係兩件事。

## 之後點加旅團返去

**唔使改 Git，亦唔使起 `data/units/<編號>/` 資料夾。**
喺 Vercel → Settings → Environment Variables 加：

```
TROOP_0082_BACKEND = https://script.google.com/macros/s/AKfyc…/exec
TROOP_0082_APIKEY  = <你張 Sheet 嘅 API Key>
TROOP_0082_NAME    = 第八十二旅深資童軍團
```

再撳 **Redeploy**。你嘅旅團就會喺旅團選擇畫面出現，**由空白資料庫開始**，
之後你喺 app 入面輸入嘅嘢會直接寫入你自己張 Sheet。

API Key 由伺服器端（`api/proxy.js`）自動補上 —— **你唔使喺瀏覽器打任何 key 或者 `/exec` 網址**。

詳見 [`ADD_NEW_UNIT.md`](ADD_NEW_UNIT.md) 方法 B。
