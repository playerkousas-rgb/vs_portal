# 把 0082 資料搬入後端，然後清走前端

> 背景：呢個系統本來淨係 for 82 旅，所以團員／團章／團費呢啲**真實資料**
> 一直放喺 Git（`data/units/0082/*.json`）同瀏覽器 localStorage。
> 要變成通用多旅團平台，就要：**先寫入後端 → 確認攞得返 → 先至清走前端。**

**清嘢係不可逆嘅。次序唔可以掉轉。**

---

## 你部機而家有幾多嘢

我喺本機種子資料度數過（你實際部機可能仲多，因為有你平時改嘅嘢）：

| 項目 | 筆數 |
|---|---|
| 團員 | 17 |
| 團章章節 | 19 |
| 團費紀錄 | 16 |
| 通告 | 2 |

---

## 第 1 步：先確認寫得入後端

前提：Vercel 已經有 `TROOP_0082_APIKEY`，而且 **Redeploy 咗**。

1. 喺**有你真實資料嗰部機**開系統（好重要 —— 唔好用一部空白機做呢步）
2. **表格與同步 → 總表同步**
3. 撳「**立即儲存到後端**」
4. 要見到「**已把整個資料庫儲存到後端**」

如果彈錯誤，照住對話框講嘅做（最常見係 `/exec` 未重新部署成「新版本」）。

---

## 第 2 步：搬遷檢查（新做嘅工具）

同一頁撳「**🛡 搬遷檢查**」。佢會**由後端攞成份資料落嚟**，同你部機逐項對數：

```
項目        呢部機   後端
團員          17      17   ✓
帳目           0       0   ✓
團章章節      19      19   ✓
團費紀錄      16      16   ✓
收支申報       0       0   ✓
…
```

* **全部 ✓** → 會綠色顯示「可以安全清走前端資料」
* **有 ✗ 或者仲有未儲存改動** → 會紅色擋住，叫你先再儲存一次

呢個掣**唔會改任何嘢**，淨係對數，撳幾多次都得。

> 點解唔信「撳咗儲存應該冇事」：`dbInfo` 只回 6 個數字，
> 團章／團費／申報／預算／借用都唔喺入面。搬遷檢查係真係 `loadDb` 攞成份落嚟數。

---

## 第 3 步：留一份離線備份（保險）

同一頁撳「**匯出 JSON 備份**」，個檔擺喺你電腦（唔好淨係擺喺 Downloads 就算）。

即使後端出事，呢個檔可以喺「資料管理 → 匯入 JSON」原樣還原。

---

## 第 4 步：清走前端資料

確認第 2 步全綠、第 3 步有備份之後，先做呢步。

### 4a. 由 Git 移除靜態資料

```bash
git rm -r data/units/0082/
git commit -m "0082 資料已搬入後端，移除靜態種子檔"
git push
```

移除之後會點：

| 情況 | 結果 |
|---|---|
| 新裝置／清咗 cache 開機 | 種子檔 404 → 資料庫空白 → **開機自動由後端讀返**（`syncBoot` 會 `dbInfo` 比對再 `pullDb`） |
| 你現有部機 | localStorage 仲有嘢，照用；改動撳「儲存到後端」先寫入 |
| 新旅團 | 本來就冇自己嘅資料夾，由空白開始 —— 唔會再見到 82 旅嘅嘢 |

我實測過呢條路：刪走靜態檔之後新裝置開機，**17 位團員、19 章團章完整由後端攞返**。

### 4b.（可選）清走瀏覽器嗰份

如果你想連自己部機都清乾淨再由後端讀一次做最終驗證：

**帳號與系統 → 資料管理 → 清空本機資料**，然後重新載入頁面 —— 開機會自動由後端拉返。

⚠️ 做呢步之前**一定要**第 2 步全綠 ＋ 第 3 步有 JSON 備份。

---

## 之後仲想做嘅嘢（唔急）

1. **`data/units.json` 嗰條 `backend.gasUrl` 仲係明文喺 Git。**
   你而家已經有 `TROOP_0082_BACKEND`（環境變數優先），所以可以由 JSON 度清走。
   但咁會令純靜態部署（GitHub Pages）冇咗後備路線 —— 你話要唔要做。

2. **Registry 頂層仲有個共用 `backend` 區塊**（舊 fallback）。
   `units.js` 已經唔會再用佢，但留喺度會令人以為仲有共用後端，建議一併清。

3. **0082 條 API Key。** 而家喺 Vercel，正確。
   如果條 key 曾經出現喺瀏覽器／截圖／對話，建議喺 Apps Script
   刪走 `API_KEY` 這個 Script Property 再行一次 `getApiKey()` 換新，然後更新 Vercel。

---

## 一頁總結

```
① 有資料嗰部機 → 立即儲存到後端      （寫入）
② 搬遷檢查 → 全部 ✓                  （驗證）
③ 匯出 JSON 備份                      （保險）
④ git rm -r data/units/0082/          （清走）
```

**②唔全綠就唔好做④。**
