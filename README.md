## 快速開始

```bash
cd ecportal
node dev-server.mjs             # 推薦（靜態＋/api，同 Vercel 行為一致）
# 或用任何靜態伺服器：python3 -m http.server 8000（必須用 http:// 開啟，唔可以雙擊檔案）
# 瀏覽器打開 http://localhost:8000
```

> **本地預覽想見到「環境變數登記嘅旅團」？** 開一份 `.env.local`（`.gitignore` 已排除，
> 有 API Key，唔好 commit），入面放 `TROOP_<編號>_BACKEND / _APIKEY / _NAME`，
> `node dev-server.mjs` 開機會自動載入——咁本地嘅旅團選擇閘就同 Vercel 生產一樣。
> 冇呢份檔嘅本地預覽，選擇閘只會有 Git 登記嘅旅團（環境變數只住喺 Vercel）。

### 第一步：揀旅團

開機第一個畫面係**旅團選擇**：揀你自己旅團，揀完先會出現**登入畫面**。
選擇會記住；登入頁有「更換旅團」掣可以返去重揀。
（直接連結 `/?u=<旅團編號>` 照用，會跳過呢一步。）

> 旅團名單喺 `data/units.json` 登記（公開資料，人人睇到）；各旅團嘅後端 `/exec` 同 API Key
> 放 Vercel 環境變數 `TROOP_<編號>_BACKEND` / `_APIKEY`（唔入 Git），加完 Redeploy 即生效；
> 詳見 [`docs/ADD_NEW_UNIT.md`](docs/ADD_NEW_UNIT.md)。每個旅團只讀寫自己嗰張 Google Sheet。

### 第一次登入（個人帳號 · 冇共用帳戶）

**2026-09-24 起：一個人一個帳號。** 登入頁只有一個門口 —— 打**自己**嘅
電郵（團長／領袖）或者 **YMIS 會籍編號**（執委／團員）＋ 自己嘅密碼；
入到去嘅權限＝你喺名冊嘅**身份**（團長／領袖／執委／團員）。

* **冇「領袖帳戶」／「執行委員會帳戶」**：舊版種落嘅共用帳戶（`acc_leader`／`acc_exco`）
  開機／由後端載入時會自動清走（`migrateSharedAccounts()`，只認種子紀錄）。
* **改身份＝改權限**：「用戶與身份」頁可以改某個人嘅身份；呢個權（`member.identity`）
  只有**團長／領袖**有 —— 執委改唔到人身份。
* **第一個開戶嗰位＝團長**：用開團 KEY 入到去（或者首位登入嘅人）會即刻
  被問「認領團長身份」；每個旅團**永遠只有一位團長**，而且**只可以轉移**
  （「用戶與身份 → 轉移團長」），唔可以喺身份下拉直接改低／自己改自己（防止鎖死）。
* **密碼**：由團長／領袖喺「用戶與身份」逐個設定；未設定嘅人未用到個人登入。
  忘記密碼 → 登入頁「忘記密碼？」用 EMAIL 自助重設（需要後端接通）。
* 首次由團長／領袖開嘅新帳戶用暫用密碼 `1234`，**入到去即刻要改**。
* 系統另有一個**唔對外公開嘅維護身份**（超管）：登入頁唔會顯示、唔會出現在任何名單，
  亦冇任何人可以改佢嘅密碼。只有團長本人知道，本文件刻意唔列出。

## 功能一覽

### 儀表板
提示中心（生日、逾期團費、待批核申報／借用、未完成行動）、本月結餘、
即將開會、團員人數、身份卡、快速連結。

### 會議
清單／看板、狀態（草稿 → 待處理 → 已確定 → 已完成）、議程、點名
（出席／遲到／請假／缺席）、會議記錄、決議行動（負責人＋到期日）、列印。

### 財務（重點）
> 日常點輸入？睇 **[docs/DAILY_ENTRY.md](docs/DAILY_ENTRY.md)**（一頁流程，可列印），或 app 內「教學 → 日常點輸入」。
* **期初結餘係「逐年」嘅**：每個財政年度各有自己嘅期初，而**本年度期初 ＝ 上年度期末**。
  例子：`2025-26` 期初 $8,803.28 → 期末 $7,846.64，所以 `2026-27` 嘅期初係 **$7,846.64**（唔係 $8,803.28）
* **現在結餘（首頁同財務頁都用呢個）**：`本年度期初結餘 ＋ 本年度收入 − 本年度支出`
  （上年度嘅帳目已計入結轉，唔會重複加）。
  儀表板有一張**帳目流程卡**逐項列出，負數會轉紅並解釋原因
  （九成係**期初結餘未填**），並提供「匯入舊帳（連期初結餘）」／「改期初結餘」捷徑
* **年度設定**（`#/finance/settings`）：**逐年期初結餘**（每年度一欄，顯示收入／支出／期末，
  並有「由上年度期末結轉」掣）＋期初日期、童軍年度起點、團費預設；
  有「用舊帳嘅數字填返」一按同時填 **2025-26 期初 $8,803.28** 同 **2026-27 期初 $7,846.64**
* **收支記帳**：收入／支出、分類、方式、單據號、相關團員、備註，即時結餘、CSV 匯出
* **財政年度報告（雙軌）**：同一批帳目自動出兩份
  * **旅財政年度**：由每年 AGM 起計 → 下屆 AGM 前一日（自務自治慣例）
  * **童軍年度**：4 月 1 日 → 翌年 3 月 31 日（總會年度）
  * 兩張表並列對比，可各自輸出 Word／PDF
  * **AGM 日期逐年輸入**（每年唔同）：報告頁一按「逐年輸入 AGM 日期」，
    逐年填實際日期；未確認嘅年份會標示，報告頁同提示中心都會提醒你更新
* **團費收款表（金額可改，唔係寫死）**：每位團員一行，一眼睇齊邊個交咗、幾時交、用咩方式、單號、入帳未。
  **團費金額設定**（標準／海外優惠／預設到期日）＋**逐個團員改金額**（✎，快捷：標準／海外／按月／半年）；
  「標記已收」時亦可改「收到金額」（部分付款）。
  按「標記已收」會**自動入帳**（分類「團費」），按「取消收款」會一齊撤銷；
  另有「開新年度團費」、「一鍵全部標記已收」、「複製催繳名單」、**逐張收據列印**、
  收款表輸出 Word／CSV。期別跟童軍年度（例：2026-27）
* **活動申報**：活動費津貼 30%、上限 $70（跟團章第 9 條）
* **預算**：預算 vs 實際
* **匯入**（支援你原本嗰張 Google Form 表）：
  * 貼上（Tab 分隔）或「檔案 → 下載 → CSV」再上載
  * 認得 **收入項目／支出項目／收入／支出／結餘／上載單據／付款人／備註** 兩欄分開嘅寫法
  * **跳過表底總結行**（上年度結餘／本年度收入／總計支出／結餘），並用嚟**對數**（✓ 或顯示相差）
  * 「20XX 年度結餘」自動認做**該年度嘅期初結餘**，並把期末結轉去下一年度，可一齊寫入年度設定
  * 「上載單據」嘅 Drive 連結會保留；「付款人」花名自動對應團員
  * 有 **團費欄**（✓／已交／團員名）時會**順便標記團費已收**
  * 匯入前有預覽（筆數、收入／支出合計、對數結果），確認先入帳
* **實測你嘅 2025-2026 分頁**：56 筆、收入 $8,630.00、支出 $9,586.64、期初 $8,803.28、期末 **$7,846.64**
  —— 可放入 `data/units/<旅團編號>/finance.reference.json` 做參考帳目（**唔會自動入帳**，
  喺「財務 → 匯入舊帳」按一下即可匯入，連期初結餘／單據連結／團費標記）

### 通告（每次一張，可分享＋報名）
* **一張通告一個公開連結**：`notice.html?u=<旅團編號>&n=<通告編號>`（免登入、只顯示該張通告）
* 類型：活動通告／會議通告／招募報名／一般通告／團員大會（AGM）
* 中英標題同內容；活動通告有日期、地點、費用、截止日期、名額
* **報名欄目自己話事**：姓名／聯絡／身份／飲食禁忌／備註…可以加、改、刪、設必填
* 發布後一按「**分享**」：公開連結、**QR Code**（可下載 SVG／列印 QR 海報）、複製 WhatsApp 文字
* 成員／家長免登入打開就睇到通告全文，順手報名；報名名單可睇／匯出 CSV／Word／列印簽到表
* 有人報名即刻出現在 APP（設定咗 Apps Script 仲會直接寫入總表「報名」分頁）
* **回覆出席與否**：報名表預設有「出席與否」欄（舊通告可一按補返）；
  詳情頁有出席表（**以名冊為本**：出席／唔出席／**未回覆**，名冊以外嘅回覆另外列出），
  可以逐個快速記錄；輸出面板可以**連通告一齊出 Word／PDF**，或者淨係出**出席回覆表（CSV／Word）**

### 手機記帳（成員自己交單，取代 Google Form）
* 公開收集頁 **`entry.html?u=<旅團編號>`**：免登入，流程係 **支出／收入 → 影相 → 揀欄目 → 金額 → 送出**
* 入口：「財務 → 收支申報 → **畀成員自己填（QR）**」→ 有 QR Code（可下載 SVG／列印海報）＋可複製網址
* 同一個對話框可以填 **Apps Script `/exec` 網址**：成員一送出就寫入總表「待批申報」（可順手上載相片去 Drive）
* 未設定都唔怕：紀錄存喺成員自己部手機，佢可以按「複製內容」傳畀司庫
* 執委／領袖喺 APP 內都有：**儀表板 →「影相記一筆」** 或 **財務 → 收支申報 → 我要申報**（相機／相簿、日期、分類、金額），批核後自動入帳

### 公開資料（免登入，畀團員／家長自己用）
側邊欄「**公開資料**」（`#/links`）把公開連結列出嚟 —— 呢啲系統唔應該只限執委用：

| 系統 | 公開頁 | 成員點用 |
|---|---|---|
| **團員入口**（要登入） | `members.html?u=<旅團編號>` | YMIS＋密碼登入 → 睇活動／通告 → **一撳 RSVP**（認名冊身份，唔使填名）→ 自動推上後端；IG／FB／網頁 ICON 直入；**我的進度**（睇獎章進度＋申報完成＋批核狀態）；過期嘢照顯示但排後＋標「已截止／已完結」 |
| 收支申報 | `entry.html?u=<旅團編號>` | 影相 → 揀欄目 → 金額 → 送出（即刻入 APP 待批清單） |
| **物資借用** | `borrow.html?u=<旅團編號>` | 揀物資（睇到**可用數量**）→ 數量 → 用途 → 送出（即刻入 APP 借用批核） |

| 團章 | `constitution.html?u=<旅團編號>` | 免登入閱讀（**後端正本**：發布＋同步即刻見到，唔使 git） |

* 每條連結：**複製** / **QR**（可下載 SVG / 圖檔）/ **列印海報**（A4 貼旅部）/ 開新分頁
* 另有「列印全部 QR 一覽」同「複製全部連結」（貼 WhatsApp 群）

* 未設定都唔怕：紀錄存喺成員自己部手機，可以「複製內容」傳畀司庫／執委
* 收到之後去邊批核：申報 → 財務；借用 → 物資；報名／出席 → 通告

### 欄位與同步（每頁自己話事，最後入一張總 Sheet）
* **欄位**：每個模組頁右上角都有「**欄位**」掣（帳目、物資、借用、團員、通告、會議）——
  欄位可以**改名、加、刪、改類型（文字／數字／日期／下拉／相片）、必填、隱藏、排序、還原預設**，儲存即刻套用到嗰頁
* **插入自己嘅 Sheet**（進階，喺「帳號與系統 → 資料管理」）：貼上旅團自己嘅 Google Sheet 連結（帶 `gid=`、
  設定「知道連結嘅人可檢視」）→ 讀欄位 → **自動對應**（日期／項目／金額／負責人…）→ 可逐個改 →
  匯入（可選先清空）或儲存做同步來源隨時再拉；亦支援直接貼上 CSV／Tab 分隔內容
* **總表同步**（進階，喺「帳號與系統 → 資料管理」）：內建 **`Code.gs`（Apps Script）** 下載 → 部署 Web App（任何人可存取）→ 填 `/exec` 網址 →
  「測試連線」（淨係讀）／「**儲存到後端**」（同頂部個掣一樣）／「由後端重新載入」／「報表同步」（只寫報表分頁）
  * 報表分頁：帳目、收支申報、物資、團員、通告、**報名**、會議、同步紀錄（每個旅團可獨立分頁或用「旅團」欄分辨）
  * 每次同步重寫該旅團嘅報表（唔會重複累積）；相片只記數量，填咗 `DRIVE_FOLDER_ID` 就會上載去 Drive 並貼連結

### 進度紀錄（一個後端、兩個前端）
旅團只有**一個後端**：一張 Google Sheet ＋ 一支 Apps Script（`/exec`）。
**深資童軍管理系統**同**進度前端**（團員／領袖用嗰個）係**兩個前端**，讀寫同一份資料 ——
所以執委系統**唔需要連去任何其他系統**：唔開分頁、唔用 portal，亦唔會出 `referer_mismatch`。

* **讀**：`GET ?action=load` → 成員、進度、待批完成、其他獎章、活動履歷（經同源 `/api/progress` 轉發）
* **寫**：`POST {action:'save'|'saveOtherBadge', apikey, changes|records}` → 直接勾／取消勾，寫入同一個 Sheet
* **批**：`POST {action:'reviewRequest'|'reviewLogRequest', apikey, request_id, decision}` → **審批中心**批准／拒絕團員申報；
  批准即刻寫入「進度追蹤」（已有紀錄會更新完成日期）／「活動履歷」，拒絕只改狀態、唔會刪紀錄
* **設定**：通常唔使填 —— 旅團後端登記喺 `data/units.json`（`backend.gasUrl` / `apiKey`）就會自動用返；
  未登記就去「進度 → 設定」填 `/exec` ＋ API Key（Apps Script 執行 `showApiKey()` 複製）。**API Key＝執委身份**
* **考核項目**：第 11 版綱要已經**內建**喺 `data/progress/items.json`（離線可用，唔使連任何網站）；
  旅團自己改過項目就喺設定填一條公開 https 網址
* **後端範本**：`Code.gs` 已經同時支援兩邊（`sync` / `claim` / `noticeSignup` / `loan` ＋ `load` / `save` / `saveOtherBadge`）；
  執行一次 `initializeSheets` 會建好 `進度追蹤`／`其他獎章`／`待批完成`／`活動履歷`／`待批履歷`／`成員名單` 分頁，
  同步時亦會更新 `成員名單`，令兩個前端見到同一批人
* **安全**：`/api/progress` 只准 GAS `/exec`、payload ≤ 1 MB、45 秒逾時，log 只記 metadata（唔記 API Key）。
  要埋讀取進度追蹤：去「進度 → 設定」貼 `/exec` 網址（Apps Script → 部署 → 管理部署）＋ API Key
  （Apps Script 執行 `showApiKey()`）→ 撳「測試連線」見到團員名單就成功（存在旅團自己嘅資料，跟 JSON 備份走）。
  想收埋條 Key 唔落前端，先設伺服器端 env（`TROOP_<旅團>_PROGRESSBACKEND` / `_PROGRESSAPIKEY`）覆蓋
* **身份對應**：團員／執委用 **YMIS（10 位數字）**、領袖用 **Email**

## 資料儲存（重要）

**寫入後端只有一個掣：頂部「儲存到後端（N）」**（2026-09-24 第五輪 團長定案；
詳見 [docs/UPDATES_2026-09-24.md](docs/UPDATES_2026-09-24.md) ⑩）：

1. **登入攞後端** —— 揀旅團 → 由後端（Google Sheet「資料庫」分頁）攞成份資料（名冊＋個人密碼）→ 再核對你嘅登入代號／密碼。**後端答唔到就一律唔准入**（登入硬閘）。
   攞到嘅嗰份 ＝ 後端嗰一刻嘅狀態，會存做「基準」（`venture82.unit.<編號>.base.v2`）。
2. **其他任何時候，改動只係寫瀏覽器** `localStorage`（`venture82.unit.<編號>.db.v2`），頂部會顯示「N 項未寫入」。
   * **冇自動寫入**（2026-09-24 加過，團長明確唔要，已拆走）—— 唔會有嘢偷偷送上後端。
   * 每個分頁自己嘅「**儲存**」掣＝寫瀏覽器；**離開分頁時若果有未撳「儲存」嘅改動會彈提示**
     （撳咗「儲存」嘅改動一律保留，等頂部掣寫入後端）。
   * ⚠️ **帳戶級改動**（開人／設密碼／改身份）未寫入後端之前，**嗰啲人喺其他裝置登唔到**
     （「身份即帳號」—— 名冊紀錄本身就係登入帳戶，登入核對讀嘅係後端嗰份）。
     所以頂部會**轉紅**寫「N 個帳戶未寫入後端」，登出／閂頁亦會擋住問。
   * 團員入口（`members.html`）交嘢行 `pushSubmit()`，唔會成份 db 寫後端。
3. **撳頂部「儲存到後端」＝ `saveToBackend()`（唯一寫入函式）**：先核對後端版本；有人喺你登入後儲存過 → 話你知，並拉成份落嚟做**三方逐格比對**：
   * 唔同格（佢加張三、我加李四；佢點李小明、我點陳大文）→ 一齊儲存；同一格同一個值 → 冇問題；
   * **同一格唔同值**（佢登記「遲到」、我登記「早走」）→ 逐格列出、**未寫入**、要你剔咗「用我嘅」再確認先蓋。
   * 所有儲存排成一條隊（`saveChain`）：連撳兩下唔會回 `busy`，會等前一次完成。
4. **跨視窗**：同一個瀏覽器另一個分頁改咗嘢，會經 `storage` event ＋ 同一套三方比對併入呢邊（`store.bindCrossTabSync()`），唔使重新整理；
   切返分頁會 `refreshIfClean()`（本機冇未存改動先至由後端拉，唔會彈衝突框）。
* 頂部「**儲存到後端（N）**」＝ 唯一寫入路；「**重新載入**」＝ 由後端拉最新嗰份。
* 未由後端載入過嘅裝置（冇基準）**唔准寫**（`no_base`），改動留喺本機。
* 首次開啟（後端仲係空）會由 `data/units/<編號>/*.json` **種子載入**一次；第一次寫入就建立後端正本。
* 備份：「帳號與系統 → 資料管理 → 匯出 JSON」；還原備份 ＝ 一次本機改動，照樣自動寫入，撞嘅格照樣會問。
* 密碼以 SHA-256 + 鹽雜湊儲存（非明文），但**純前端系統唔應該存放敏感個人資料**
* 未接後端之前，唔好放電話／身份證等敏感資料；團章公開頁只會顯示你發布嘅團章文字

任何靜態主機都可以（GitHub Pages / Netlify / Cloudflare Pages / 內網 NAS）：

1. 上載整個資料夾（記得包含 `data/`）
2. 網址加 `?u=<旅團編號>` 指定旅團（單一旅團可直接設定 `data/units.json` 嘅 `defaultUnit`）
3. 想公開團章：將 `constitution.html` 同 `data/units/<旅團編號>/constitution.json` 一齊上載，
   QR Code 就會指向公開頁；亦可以喺「團章 → 公開網址」填自訂網址
4. 想公開通告／收手機記帳：同樣要上載 `notice.html`、`entry.html`、`data/units.json`、
   `data/units/<旅團編號>/notices.json`（公開頁會讀呢啲檔；`entry.html` 只讀 `unit.json` 嘅基本資料）
4. 進度紀錄：旅團後端登記喺 `data/units.json`（`backend.gasUrl` / `apiKey`）就會自動用返；要覆蓋先喺「進度 → 設定」填 `/exec` ＋ API Key
   （**需要支援 `/api/` 嘅部署**：Vercel 或本機 `npm run dev`；純靜態主機冇 API，進度接駁會停用）

## 已知限制 / 待跟進

1. **財務歷史資料**：2025-2026 分頁（gid 972824038）已完整內建做參考資料（56 筆 + 期初結餘），
   一鍵可匯入。其他年度分頁如有需要，將連結（連 `gid=`）發我，我可以同樣內建。
2. **AGM 日期**：現時用「8 月最後一個星期六」推算 2023–2026 並標示「未確認」，
   請到「財務 → 財政年度報告 → 逐年輸入 AGM 日期」填每年實際日期（每年唔同）。
3. **進度紀錄**：一個後端、兩個前端 —— 深資童軍管理系統同進度前端讀寫同一份資料，冇外連、冇 portal。
   後端要係本系統嘅 `Code.gs`（支援 `?action=load` / `action=save`），`npm run build:gas` 會由範本產生。
4. **多裝置同步**：登入攞後端 → 本機改 → 撳「儲存到後端」（三方逐格比對，撞先問）—— 見「資料儲存」一節。
   兩個人**同時**改同一格仍然要有人揀；系統唔會自己猜。
5. **團員職位／聯絡**：名冊暫只有姓名＋生日（來自生日表），其餘欄位待你補充
   （亦可以直接喺「用戶」頁右上「欄位」自己加欄位）。
6. **公開收集頁需要託管**：`entry.html` / `notice.html` 要放喺 https 網址（Vercel / GitHub Pages 等）先方便成員用手機開；
   純本機 `localhost` 只適合測試。
7. **進度讀寫需要 `/api/` 後端**：Vercel 部署自動有；本機用 `npm run dev`；
   GitHub Pages 之類純靜態主機冇 API，進度頁會提示（其他功能照用）。
   * 旅團後端要係本系統嘅 `Code.gs`（或已支援 `?action=load` / `action=save`）；`npm run build:gas` 會由範本產生 `apps-script/Code.gs`。
8. **Apps Script 版本**：你嗰條 `/exec` 而家冇 `doGet`（只有 `doPost`）；建議貼上內建 `Code.gs` 並用
   「管理部署作業 → 編輯 → 新版本」更新（網址不變），咁 `sync` / `claim` / `noticeSignup` 三個動作就齊。
