# 2026-09-24 更新（已由 2026-11 安全架構取代）

本文件原先描述的「公開資料／免登入通告／免登入團章／匿名收支申報／匿名借用」方案已撤回，不能再作為產品或後端契約。

## 現行規則

- 支部內容沒有匿名可見層；最低可見級別是本支部已登入團員。
- 舊 `vis: "other"` 會安全收窄為最低已登入身份，不保留匿名語義。
- `notice.html`、`constitution.html`、`entry.html`、`borrow.html` 只保留舊網址轉向；不再讀取或提交資料。
- 團員內容由 `members.html` 登入入口取得。後端使用 opaque session 對回名冊本人，再按本支部身份及內容可見級別產生正面白名單投影。
- 通告回覆使用本人專用 action；`memberId`、姓名及身份由後端 session 決定，不能由瀏覽器自報。
- 側欄每個模組分開管理 `show`、`read`、`edit`：`show` 只控制導覽，`read` 同時保護直接網址及後端投影，`edit` 保護寫入。
- 權限只可管理嚴格較低身份；低身份獲得的權限會向高身份單調繼承。
- 跨支部資料不會用匿名網址分享。正式契約必須分開三道授權：
  1. 來源支部批准分享一個完整、具版本的資料包；
  2. 接收支部明確接受該資料包；
  3. 接收支部再授權哪些本地身份可以閱讀或使用。
