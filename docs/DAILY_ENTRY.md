# 平時點輸入？（司庫／執委用嘅一頁流程）

> 貼喺物資房／會議室都得。所有操作都喺 **財務** 頁：帳目 · 財政年度報告 · 團費 · 收支申報 · 活動預算 · 匯入舊帳。

---

## 0. 一句話：四種入法

| 情況 | 用邊個入口 | 要填幾多樣 |
|---|---|---|
| 有人交錢 / 有收入 | **財務 → 新增收支**（收入） | 金額、日期、項目 |
| 你墊支買咗嘢 | **財務 → 收支申報 → 我要申報**（可以**影相**） | 影單據 → 金額、日期、項目、分類（批核後自動入帳） |
| **成員自己交單**（取代 Google Form） | **手機開 `entry.html?u=0082`**（掃 QR） | 影相 → 揀欄目 → 金額、項目、姓名（免登入） |
| 開完會／活動一次過補 | **財務 → 匯入舊帳**（貼上或上載 CSV） | 一段表：日期、類型、項目、金額 |
| 收團費 | **財務 → 團費**（收款表） | 喺團員一行按「標記已收」，自動入帳 |

---

## 0.5 成員自己影相交單（最快，連 Google Form 都唔使）

1. 領袖／執委：**財務 → 收支申報 → 右上「畀成員自己填（QR）」**
2. 彈出 QR Code →「下載 SVG」或「**列印 QR 海報**」→ 貼喺團址／WhatsApp 群
3. 成員用手機掃 QR → **① 揀支出／收入 → ② 影相 → ③ 揀欄目 → ④ 打金額、項目、姓名 → 送出**
4. 喺對話框貼上 **Apps Script `/exec` 網址**（同「表格與同步 → 總表同步」可以共用同一個）：
   成員一送出就**直接寫入總表**「待批申報」分頁；未設定就存喺成員部手機，
   佢可以按「複製內容」傳畀司庫
5. 司庫收到 → 「收支申報 → 批准並入帳」→ 自動入帳（相片一齊跟）

> 執委／領袖自己填都一樣：**儀表板 →「影相記一筆」**。
> 詳細設定步驟睇 **[MASTER_SHEET.md](MASTER_SHEET.md)**。

---

## 1. 最常用：30 秒記一筆

1. 財務 → 右上「**+ 新增收支**」
2. 揀 **收入／支出** → 打 **金額**（用數字就得，唔使打 `HK$`）
3. **日期** 自動填今日（要改就改）
4. **項目** 寫清楚：例「全團大會場地租金」「12/7 partyroom」「曉莉 團費」
5. 揀 **分類** 同 **方式**；有單據就勾「已收到單據」＋填單號
6. 按「新增帳目」→ 結餘、月結、年結自動更新

**記帳三句真言**

- **分類要一致**（同一個意思永遠用同一個分類，年結才靚）
- **項目寫得具體**（三個月後你自己都睇得明）
- **單據有編號**（有單冇單，一查就知）

## 2. 團費：記錄邊個交咗（**金額可改，唔係寫死**）

**財務 → 團費** 有一張**收款表**：每位團員一行，一眼睇齊邊個交咗、幾時交、用咩方式、單號幾多、入咗帳未。

### 團費銀碼喺邊度入？

| 想改嘅範圍 | 位置 |
|---|---|
| **標準團費**（每位每年） | 團費頁 →「**團費金額設定**」→ 標準團費（例：$360） |
| **海外／優惠團費** | 同上 → 海外／優惠（例：$90）；留空就自動用標準嘅 1/4 |
| **預設到期日** | 同上（`{y}` = 年度首年，例 `{y}-09-30`） |
| **某一位團員** | 收款表該行右邊嘅 ✎ → 打自訂金額（快捷：標準 / 海外 / 按月 / 半年） |
| **開新年度時逐個填** | 「開新年度團費」對話框：每人一行可改，亦可「全部 $360 / 全部 $90」 |
| **收錢當刻** | 「標記已收」對話框入面有「**收到金額**」（部分付款都得） |

| 想做嘅事 | 點做 |
|---|---|
| 開新年度 | 「**開新年度團費**」→ 每人金額可逐行改 → 建立紀錄（同一年度唔會重複） |
| 有人交錢 | 喺佢一行按「**標記已收**」→ 填**收到金額**／日期／方式／收據號 → **同時自動入帳**（分類「團費」，唔使入兩次） |
| 按錯咗 | 按「**取消收款**」→ 改回未收，相關帳目一齊撤銷 |
| 要收據 | 按 🖨 → 即刻列印／存 PDF（有司庫簽署位） |
| 追人 | 「**複製催繳名單**」→ 貼落 WhatsApp 群；或輸出收款表 Word／CSV 貼堂 |
| 一次過收齊 | 「**一鍵全部標記已收**」→ 全部標記今日已收並自動入帳（會有二次確認） |
| 中途入團／海外 | 按 ✎ 改成實際金額（例：6 個月 $180、海外 $90） |

> 期別跟**童軍年度**：2026 年 9 月收嘅係 **2026-27** 年度。

---

## 3. 月結（每月 5 分鐘）

1. 財務 → **帳目**：篩選月份，睇收入／支出合計
2. 睇「**未收團費**」同「**待批核申報**」，跟一跟
3. 輸出 Word／PDF 一份存檔或貼上群組

## 4. 年結（AGM 前）

1. 財務 → **財政年度報告**
2. 逐年確認 **AGM 日期**（未確認會有黃色提示；每年唔同，唔可以一次填死）
3. 按「**Word（兩份報告一份文件）**」或「PDF」→ 有齊期初、收入、支出、淨額、期末結餘
4. 另外出「**童軍年度（4/1–3/31）**」嗰份交總會／存檔

## 5. 由 Google Sheet 搬舊帳（一次過）

1. Google Sheet → **檔案 → 下載 → 逗號分隔值 (.csv)**
2. 82venture → 財務 → 匯入舊帳 → **上載 CSV 檔**
   （或者喺 Sheet 選取範圍 `Ctrl+C`，直接貼落個格）
3. 睇預覽：讀到幾多筆、收入／支出合計、認得出邊幾位交咗團費
4. 按「**確認匯入**」→ 帳目同團費紀錄一齊建立；錯嘅可以逐筆刪

### 欄位可以點寫（照你原本嘅中文字就得）

| 欄位 | 接受的寫法 |
|---|---|
| 日期 | `2025-12-07`、`2025/12/7`、`7/12`（冇年份當今年） |
| 類型 | `收入`／`支出`／`income`／`expense`（「支」「付」都認） |
| 項目 | 自由文字，例：`12/7 partyroom event` |
| 金額 | `190`、`HK$190.00`、`1,360`、`-57`（會自動清洗） |
| 分類 | 團費／活動費／場地／物資／膳食…（空白會俾預設值） |
| 方式 | 現金／轉數快 FPS／銀行轉賬／PayMe… |
| 經手人（負責人） | 名字，例：嘉詠 |
| 年度 | `2025-26`（會記入帳目，方便對年度） |
| **團費** | 打 `✓`／`Y`／`已交`／`已收` → 系統會**順便標記該團員團費已收**；寫團員名都認 |
| 備註 | 自由文字 |

### 你原本嗰張 Google Form 表（實測過）

欄位次序 `時間戳記 / 日期 / 收入或支出 / 收入項目 / 支出項目 / 收入 / 支出 / 結餘 / 上載單據 / 付款人 / 備註` **可以直接貼**。系統會：

1. 認得收入／支出分開兩欄（連 `HK$1,140.00` 呢種寫法）
2. **跳過表底總結行**（上年度結餘 / 本年度收入 / 總計支出 / 結餘），用嚟**對數**
3. 認得「2024年度結餘」= **期初結餘**（匯入時可一齊寫入年度設定）
4. 保留「上載單據」嘅 Drive 連結
5. 「付款人」寫花名都對應到團員（例：`大文` → 陳大文），團費會自動標記已收
6. 顯示 **期初 ＋ 收入 − 支出** 同原表總結比較，對得啱會有 ✓

> 實測你嘅 2025-2026 分頁：**56 筆**、收入 $8,630.00、支出 $9,586.64、期初 $8,803.28、期末 **$7,846.64** —— 同原表總結完全一致。
> 已放入「財務 → 匯入舊帳 → 參考：你現行 Google Sheet 紀錄」，按一下就可以匯入（連期初結餘、單據連結、團費標記）。

> 支援引號欄位、欄位內逗號／換行、千分位、負數；
> 「BAD deb」呢類**標題行會自動跳過**。
> 想跟格式填？「匯入舊帳」頁有「**下載記帳範本 CSV**」。
